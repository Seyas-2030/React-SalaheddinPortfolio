# 🚀 Salaheddin Developer Portfolio | معرض أعمال صلاح الدين

## 📌 الوصف المختصر (Description)
- **العربية:** موقع معرض أعمال (Portfolio) شخصي تفاعلي ثلاثي الأبعاد يستعرض المشاريع والمهارات البرمجية ووسائل التواصل بتصميم عصري متجاوب.
- **English:** An interactive 3D personal software developer portfolio showcasing full-stack projects, technical skills, and contact links with a modern responsive UI.

## 🎯 المشاكل التي يحلها المشروع (Problems Solved)
- **العربية:** توحيد جميع المشاريع البرمجية والمهارات في واجهة تفاعلية احترافية تسهّل على جهات التوظيف والعملاء تصفح الأعمال وتقييم الخبرة التقنية.
- **English:** Centralizes all software engineering projects and skills into an engaging, recruiter-friendly showcase.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend:** React.js, TypeScript, Tailwind CSS
- **3D Graphics & Tooling:** Three.js, Vite
